# 💼 Portfólio — Alan da Silva do Carmo

> **Desenvolvedor de Software | Python & JavaScript**

Portfólio profissional moderno e responsivo, construído com React, Vite, Tailwind CSS e Framer Motion. Projetado para destacar competências técnicas, projetos reais e trajetória profissional com um design premium e de alto impacto visual.

---

| Categoria       | Tecnologia                          |
| --------------- | ----------------------------------- |
| **Framework**   | React 19                            |
| **Build Tool**  | Vite 8                              |
| **Estilização** | Tailwind CSS v4                     |
| **Animações**   | Framer Motion                       |
| **Ícones**      | Lucide React + SVG customizados     |
| **Tipografia**  | Inter + JetBrains Mono (Google Fonts) |

## ⚡ Instalação e Execução

```bash
# 1. Clone o repositório
git clone https://github.com/maiornerd/Alan-do-Carmo.git
cd Alan-do-Carmo

# 2. Instale as dependências
npm install

# 3. Inicie o servidor de desenvolvimento
npm run dev

# 4. Para build de produção
npm run build

# 5. Para preview do build
npm run preview
```

## ✨ Funcionalidades

- **Design premium** com glassmorphism, gradientes e micro-animações
- **Modo escuro** elegante com paleta ciano/roxo
- **Partículas animadas** no background (Canvas API)
- **Navegação suave** com scroll spy e destaque da seção ativa
- **Menu hamburger** responsivo para mobile
- **Barras de progresso** animadas nas competências técnicas
- **Timeline** de experiência profissional
- **Cards de projeto** com links para GitHub
- **Botão flutuante** "Voltar ao topo"
- **SEO otimizado** com meta tags e Open Graph
- **Totalmente responsivo** — desktop, tablet e mobile
- **Acessível** com labels ARIA e semântica HTML5

## 🌐 Deploy

O projeto está configurado para deploy direto na **Vercel** ou **Netlify**:

### Vercel
```bash
npm install -g vercel
vercel
```

### Netlify
1. Faça build: `npm run build`
2. Faça upload da pasta `dist/` no painel do Netlify
