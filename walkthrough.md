# 🎨 Portfólio Profissional — Alan da Silva do Carmo

## Resumo

Portfólio moderno e premium criado com **React 19 + Vite 8 + Tailwind CSS v4 + Framer Motion**, pronto para deploy na Vercel/Netlify.

## Stack Técnica

| Tecnologia | Uso |
|---|---|
| React 19 | Componentes reutilizáveis |
| Vite 8 | Build tool ultrarrápido |
| Tailwind CSS v4 | Estilização utilitária |
| Framer Motion | Animações suaves |
| Lucide React + SVGs | Ícones modernos |
| Canvas API | Partículas animadas |

## Seções Implementadas

1. **Hero** — Nome, título, badge "Disponível", 3 CTAs com efeito glow
2. **Sobre Mim** — Narrativa profissional + 4 cards de destaque
3. **Objetivo Profissional** — Glass card com meta de carreira
4. **Competências Técnicas** — 5 categorias com barras de progresso animadas
5. **Projetos** — 2 projetos reais com tech tags e links GitHub
6. **Experiência Profissional** — Timeline elegante com 3 posições
7. **Formação & Idiomas** — Cards acadêmicos + barras de idiomas
8. **Contato** — 4 cards coloridos (Email, LinkedIn, GitHub, Localização)
9. **Footer** — Brand, links rápidos, redes sociais, copyright

## Funcionalidades Avançadas

- ✅ Partículas Canvas com conexões entre nós
- ✅ Navbar sticky com glassmorphism e scroll spy
- ✅ Menu hamburger animado para mobile
- ✅ Animações de entrada com Framer Motion (useInView)
- ✅ Barras de progresso com gradiente animado
- ✅ Timeline com linha gradiente e dots luminosos
- ✅ Botão flutuante "Voltar ao topo"
- ✅ SEO completo (meta tags, Open Graph, semântica HTML5)
- ✅ Responsividade total (desktop, tablet, mobile)
- ✅ Custom scrollbar com cor tema
- ✅ Gradient text animado
- ✅ Fonte profissional Inter + JetBrains Mono
